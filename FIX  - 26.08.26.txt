1. Цель проекта
Создаём робот/аналитический движок для SPX 0DTE, который:
•	непрерывно получает рыночные данные;
•	определяет состояние рынка;
•	выбирает подходящую стратегию;
•	автоматически подбирает страйки;
•	рассчитывает риск;
•	контролирует открытую позицию;
•	имеет несколько независимых механизмов выхода;
•	на первом этапе работает только в сигнальном режиме, без реальной отправки ордеров.
Главный принцип:
Сначала надёжность данных → потом расчёты → потом сигналы → потом защита → и только после тестирования возможна автоматизация исполнения.

2. Источник данных
В качестве основного источника для первой версии выбран Tradier.
Актуальная документация подтверждает наличие API для рыночных данных, опционных цепочек и потоковых данных. Production используется для реальных рыночных данных, sandbox — для тестирования и задержанных данных. T Tradier API+1
Для потоковой части Tradier предоставляет HTTP Streaming и WebSocket Streaming. T Tradier API
Особенно важно для SPX:
•	у SPX недельные опционы используют отдельный корень SPXW;
•	при поиске экспираций нужно учитывать includeAllRoots;
•	API имеет отдельный endpoint для поиска опционных символов. G GitHub
