FIX — 27.08.26 FINAL
SPX 0DTE / OPRA — точка фиксации проекта
1. Цель проекта
Проект SPX-0DTE-Strategy-Engine предназначен для использования реальных рыночных данных SPXW 0DTE для последующего построения аналитики и торговых сигналов для стратегий 0DTE SPX.

Текущий этап — сбор и подтверждение качества данных. Торговые ордера пока не используются.

2. Принцип проекта
Основная последовательность:

реальные данные → структура опционной цепочки → расчётные показатели → сигналы → защита → автоматизация

Разработка следующего слоя производится только поверх уже подтверждённой рабочей основы.

Не допускается возвращение к уже доказанным этапам без конкретной технической причины.

3. Источник данных
Используется:

IBKR TWS / API → OPRA → SPXW options

Работа выполняется через Paper TWS.

Текущий API endpoint:

127.0.0.1:7496

Используется SPXW (tradingClass).

4. Что сегодня подтверждено
Создан и запущен:

SPXW_LIVE_ENGINE.py

Движок:

автоматически определяет сегодняшнюю дату New York;
работает с SPXW 0DTE;
получает конкретные option contracts;
использует reqMktData();
создаёт постоянные L1 subscriptions;
получает потоковые:
BID;
ASK;
LAST;
VOLUME;
одновременно отслеживает Call и Put;
не отправляет ордера;
не изменяет настройки TWS;
корректно отменяет market-data subscriptions при завершении.
5. Фактический результат
Проверен диапазон:

7630–7730, шаг 5 пунктов.

Всего:

21 strike × 2 стороны = 42 option contracts.

Результат:

L1 LIVE: 42/42

То есть на данном тесте подтверждено получение потоковых L1 данных для всех 42 SPXW контрактов.

В течение наблюдения BID/ASK изменялись в реальном времени, что подтверждает именно потоковое обновление данных, а не однократный snapshot.

6. Что пока НЕ утверждается
Текущий результат не означает, что весь будущий Strategy Engine уже готов.

Пока отдельно не завершены:

автоматическое определение фактического ATM;
построение полной необходимой option chain;
Put Interest / Open Interest как отдельный источник данных;
OTM / ITM классификация;
Expected Move;
расчёт производных показателей;
торговые сигналы.
Эти этапы являются следующим уровнем, а не частью сегодняшнего доказательства L1.

7. Важное техническое наблюдение
Текущий монитор использует фиксированный anchor:

7680

и диапазон:

±10 strikes / 50 SPX points.

Это было сделано для подтверждения стабильного получения данных.

7680 не следует считать окончательным ATM.

Автоматическое определение ATM должно быть следующим отдельным этапом.

8. Состояние после теста
Тест завершён штатно через:

Ctrl+C

После остановки:

subscriptions отменены;
соединение закрыто;
ордера не отправлялись.
9. Финальный статус 27.08.26
L1 SPXW 0DTE через IBKR/OPRA — подтверждён.

42/42 contracts — live.

Это является новой контрольной точкой проекта.

Следующий этап должен продолжать работу с этого состояния, а не повторять доказательство L1.

10. Ограничение расходов
Сохраняется принцип:

Никаких дополнительных платных подписок, Live-счёта или реальных ордеров, пока конкретная функция не будет доказана как технически невозможная без них.

11. Следующая логическая задача
На основе уже подтверждённого L1 перейти к следующему слою:

автоматическое определение ATM → построение рабочей структуры цепочки → расчёт необходимых показателей → подготовка данных для будущих торговых сигналов.

Не переходить к торговым ордерам.
